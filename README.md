Problem Statement:
Build a complete real estate analytics solution using Python for advanced data cleaning, load the refined dataset into a SQL database, and use Power BI to directly connect to SQL and build a dashboard. 
The goal is to replicate a real-world enterprise-level data pipeline and analysis environment using a complex housing dataset with 1,00,000+ records.
Objectives:
Understand the impact of amenities, pricing, and location on booking success.
Identify top-performing builders and micro-markets.
Provide business insights for decision-makers using Power BI dashboards.

Tools & Technologies:
PostgreSQL – SQL queries for validation.
Python (Pandas, Matplotlib/Plotly) – data cleaning & preprocessing.
Power BI – interactive dashboard & visual insights.

Data Cleaning & Preprocessing:
Removed duplicate entries.
Treated null values.
Removed negative or unrealistic values.
Derived new metrics.

Dashboard Creation in Power BI:
The dashboard consists of multiple interactive visualizations:
Amenity Impact – Scatter plot: Amenity_Score vs Booking_Conversion_Rate.
Booking Conversion – Stacked column chart by Micro_Market.
Sales Channel Efficiency – 100% stacked column chart by Booking_Status.
Top Performers – KPI cards for Top 5 Builders by Revenue & Bookings.
Geographical Insights – Map visualization of micro-markets.
Possession status analysis.
Market trends.
configuration demand.
Quartely builder contribution.

Market Insights:
